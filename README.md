# 🏁 Retrowave Racer

Juego de carreras retrowave en pixel art, con vista desde detrás del coche.

▶️ **Jugar online:** https://jeffryjt.github.io/KiroVideoGameCAR/

## Cómo jugar

- **← →** (o **A / D**): cambiar de carril
- **ENTER**: empezar o volver a jugar
- Esquiva los coches. Cuanto más tiempo sigues vivo, más puntos ganas.
- Cada **1000 puntos** sube el nivel y vas más rápido.
- Si entras en el **Top 10 de pilotos**, escribes tu nombre.

## Objetos

| Bonus | Efecto |
|---|---|
| 🪙 Moneda | +250 puntos |
| 🛡️ Escudo | Aguanta 1 choque (8 s) |
| ✖️2 Puntos X2 | Puntos dobles (7 s) |
| ⏱️ Reloj | Cámara lenta (4 s) |

| Trampa | Efecto |
|---|---|
| 🛢️ Aceite | Controles al revés (4 s) |
| 🟤 Barro | Vas lento y casi no sumas puntos (3 s) |
| 🌫️ Niebla | No ves lo que viene (5 s) |

## Tecnología

Un solo archivo `index.html` con HTML5 Canvas y JavaScript. No hace falta instalar nada.
El Top 10 se guarda en el navegador (`localStorage`).
